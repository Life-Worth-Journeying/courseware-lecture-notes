# 逐页讲解规范

> 本文件是课件逐页讲解的完整规范。`build_template.py` 会把本文件嵌入生成的模板；
> 也可以直接作为 Agent 的讲解规范阅读。`{{MIN_CHARS}}` 是篇幅起点，默认 900。

## 讲解规范（通读一次，逐页按需取用）

**先认小标题（动笔第一步，最重要）** — PPT 页里的小标题和正文常常混成一片，必须先分层再讲：把版面上独立成行的小标题找出来——编号行（1.1、1.3.1、一、、（二）、Chapter 2、Section 3.4）、加粗或大字号的短行、以及「阻抗矩阵」「边界条件」这类中文短语；它们不是正文句子。每条译成中文、首次出现括注原文，用 `### 中文小标题` 单独占一行、前后各空一行，作为下面正文的分块界线。
  逐页骨架里给的「本页小标题」只是从文字层认出来的线索，以截图为准补齐或纠正；课件没有小标题的页就整页写成连续自然段，一个 `###` 都不加。不要把标题名揉进句子里，不要把正文短句升级成标题，也不要自己另起一套小节名。

**怎么讲** — 每条小标题下面各写几段，按下面顺序自然衔接：
1. 定位：开头一两句说清这页在整章里解决什么问题、与上一页什么关系。
   连续内容块只写一次定位：先看相邻几页是否在讲同一个论证、推导或例题，
   是则视为一块——定位句只写在块的首页，块内其余页直接从续接的公式、定义或论点开始，
   一律不要再写"本页接着上一页""承接上页""在上一页结论基础上"这类复述上页的开头；
   只有换了主题或另起一个独立小节时才重新定位。块内用"由上式""代入得""于是"就地衔接，
   不要回头重述上页结论；`###` 小标题本身标明新块起点，标题后不接"本页接着…"。
2. 翻译：课件是外文时，把标题、术语、定义、图注、坐标与符号说明译成中文，
   给通行译名（英文原文最多括注一次，之后只用中文名，别每个词都带一遍）；
   符号、缩写、上下标首次出现要说明含义。不要整段照抄原文，也不要逐句直译。
3. 按版面顺序讲：动笔前先把这一页按版式拆成几块——页标题、各条小标题、
   主体（自上而下、自左而右）、图与表、页脚与旁注；讲解严格照这个视觉顺序推进，
   遇到一条小标题就用一条 `###` 起头、把这一块讲完再进下一条，禁止把不同小标题下的内容串成一段，也不要这里讲一句、那里又跳回来，更不要先讲页面下半的东西再回头讲上半。
   转入新的一块时用半句话点明位置和对象（“页面左上的定义式”
   “右侧这张图”“下方那张表”），让读者能跟着眼睛走；但课件上的红笔字、手写批注、圈画只是提示你该怎么讲，不要连引号一起抄进正文，把意思用自己的话说出来。同一块内部固定顺序：
   先说它是什么、再看怎么来的、最后说它说明什么；图里读到的量、趋势、坐标范围
   要写进句子，不要只写“如图所示”。图不是配图说明：先接本页文字或公式，说明这张图在回答什么问题、验证什么关系，再把坐标、曲线、交点、结构、标注与正文符号和结论一一对应；只写影响结论的视觉细节，不逐项描述颜色、形状和版式，没有信息量的装饰图不写；图与正文冲突时以文字/公式为准，并指出冲突。
4. 推导要补全：关键公式给完整推导，每一步注明依据（定义、定理、边界条件、
   近似假设、坐标变换、守恒关系）。课件常只写结论或掐掉中间几步，这种情况必须
   从定义式、或从上一个已经成立的式子出发自己补齐，必要时点一句“课件这里跳过了
   ……，补上这一步”，再推到课件给出的结果；不能因为课件没写就略过。不跳步，
   不写“显然”“易得”；多行推导用 $$…$$ 独立成行、前后空一行，
   推完用一句话说结果意味着什么。
5. 物理意义：讲清每个量的量纲、几何与物理含义，正负号和方向代表什么，
   在极限、特例、退化情形下的行为，结论成立的前提与失效边界；能联系前后页就点一句。
6. 辅助理解：抽象、反直觉、易混处就近补一个具体数值例子、一个类比、一张对比表，
   或一段几何图像的描述；类比直接写进句子，不写“打个比方”“通俗地说”这类提示语。
7. 易错点：指出常见误用、符号混淆、单位与量纲、适用条件被违反时会怎样。
8. 收束：页末一两句把本页结论接向下一页，不要另起“小结”标题。

**公式与字母怎么写得顺（一个都不许删）** — 本节只改呈现方式，不删内容：
- 符号首次出现给中文名和读法：`$athbf{E}$（读作 E，电场强度）`；之后
  尽量用中文名指代，别让一段里裸字母连成一串；同一符号前后写法一致，
  不要 E / `$\vec E$` / `$\mathbf E$` 来回换。
- 每个独立公式前面一句引子（由什么条件、对哪个量做了什么），后面紧跟一句
  中文把它读出来（左边是什么、右边是什么、等于在说什么），再谈量纲、前提
  与失效边界；`$$` 块绝不能孤零零砸在段落中间。
- 一个自然段里行内 $…$ 最多 3~4 个，多了就拆段或先用中文把关系讲完、
  再独立列式；符号多时用「符号 | 中文名 | 含义与单位」表格对照，
  符号照样逐个写全——表格是换一种摆法，不是省掉。
- 长推导一步一个 `$$` 块，块间用中文承接（“把它代入上式”“对两边取旋度”）；
  外文缩写首次出现展开并给通行译名，之后统一用译名或同一个符号。
- **公式、字母、上下标、矢量记号、系数、适用条件一个都不能少**，这里只调
  叙述顺序和呈现方式，绝不为顺口删式子。

**定义和分类写成能记住的话（不要堆括号）**
- 一个括号只装一层补充，绝不括号套引号、引号里再套括号；定义写成直陈句
  “若…则称为…”“…指的是…”“…要求…”，别用破折号把三四个定义串成一句。
- 相近的几个概念（如广义 / 严格 / 判据）先用一句话说清共同点和唯一区别，
  再分条展开；一个自然段只讲清一个概念。
- 引用其它页写“第9页”，不要写“P9”；本页写“这一页”即可。
- 段末收束最多一句，别堆“与 A、B 共同构成 C 的 D 基础”这类多层定语；
  要讲联系就另起一句，说清楚它后面用在哪。

**去 AI 味（humanizer 规范，整理自 blader/humanizer v4.0.0 的 26 条模式）**
- 底线：公式、字母、上下标、系数、条件、数值、页码、引用、==高亮==、
  `###` 小标题、编号列举逐条分行的结构全部原样保留；**不新增课件与原文里
  没有的事实、数值、例子或细节**，只改表达方式。删改或编造算最严重的问题。
- 最强、见到就改的五种：① “不是…而是…”“不只是…更是…”这类先否定再抬高
  （直接说结论）；② 段末重复上文的短句收尾（“这才是关键”“值得注意的是”），
  和“这说明了…的重要性”这类替读者点题的句子（删掉或换成新信息）；
  ③ “说到底 / 归根结底 / 本质上是 / 其核心是”这类假装深刻的格言（换成具体结论）；
  ④ “让我们深入 / 先来看看 / 需要知道的是 / 坦率地说”这类铺垫开场（直接进正题）；
  ⑤ 和没提出的反对意见辩论（“我并不是说…”“有人可能会说…”），删掉虚构对手。
- 节奏与排版：不硬凑三项并列，按内容实际需要几项就几项；连续几句别用同一
  主语起头；破折号（— / –）别当万能连接词，改成句号、逗号、冒号或括号（一处
  不是问题，满篇才是）；名词后别滥用连字符复合词；被动句能点明主语就用主动句。
- 措辞：AI 高频词成串出现要换朴素说法——此外、助力、至关重要、深入探讨、
  彰显、图景、交织、错综、关键 / 基石 / 里程碑、showcase、tapestry 等；
  夸大重要性的“标志着重要时刻”“体现更广泛趋势”“前景光明”留事实去渲染；
  堆限定词的“可能也许大概”只留一层；“象征着…”“反映了…”这类硬拔高的 -ing
  短语只留有依据的；推销腔（“坐落于壮美的…”“令人惊叹的”）直说它是什么；
  无出处的“专家认为 / 业内报告”要删或点名真实出处；回避“是 / 有”的长短语
  直接用“是 / 有”。
- 别给每个词加粗、别给每条列项加“标签：”；标题用句式大小写、不加表情和
  箭头、不画分隔线；该用直引号的地方别用弯引号。
- 聊天残留一律删：“希望对你有帮助”“好问题”“当然可以”“还需要我…吗”；
  知识边界声明和猜测（“据我所知”“可能出生于…”）删掉或改成“资料未写”；
  标题后重复标题的那句话删掉；讲文档本身（“本节介绍…”“下表对比…”）改成
  直接讲内容；替读者重复他已知背景的，结论先行。
- 语气：教材式技术讲解保持中性、清楚、克制，不要为了“有人味”加入个人
  情绪、段子或跑题；句式长短交错即可，术语译名与符号写法照旧。

**怎么标** — 层级与记号，只在真正关键处用：
- `## Pn` 是页标题（原样保留，不要改动或新增）；课件原有的小标题用
  `### 中文小标题（原文）` 单独成行、前后各空一行；层级只有这两级，
  不要用 # 或 ####，课件没有小标题的页整页都是连续段落。
- 编号列举逐条分行：课件里 (i)(ii)(iii)、(1)(2)(3)、①②③ 这样一条条列出的
  条件 / 定义 / 事实 / 步骤，认出来后一条占一行、逐条分段列出（前后空行），
  像原文清单那样齐整；绝不用中文分号把几条揉进同一段。编号照抄、内容紧跟编号；
  只有正文顺带提到某一条（如“条件 (ii) 保证…”）才留在句子里，不必拆。
- ==…== 标要背的结论、定义、易错点，每页 1~3 处；会自动渲染成黄底并汇入重点索引。
- **加粗** 标关键术语；多个方法、条件、符号的异同一律用 Markdown 表格对比。
- 关键公式表：本页公式较多或需横向比较时，用表格列「公式 | 含义与适用条件 | 与谁相关」，
  公式写在 $…$ 里；公式少就不必做表。
- 公式一律 LaTeX：行内 $...$，独立 $$...$$；符号首次出现先定义。
- 求和 / 连乘必须写全上下限，如 `$\sum_{\nu=1}^{3}$`，不能只写 ∑ 或把上下限省掉；
  向量用 `$\vec A$`，单位矢量用 `$\hat u_\nu$`，并矢用 `$\overline{\overline{A}}$`。
- 行列式用 `\begin{vmatrix}…\end{vmatrix}`，矩阵用 bmatrix / pmatrix，分段用 cases；
  矩阵内用 & 分列、\\ 分行，矩阵里不写中文；不要用 `\left|…\right|` 再包 matrix。
- 一个 $$ 块只放一个完整公式；矩阵、求和与说明文字不要塞进同一块，
  否则行列式会被拆散。多行推导拆成多个 $$…$$，不要用 aligned 的 & 对齐符。
- 不写 HTML、颜色标签、代码块，不自造小标题，不把标题名揉进正文。

**全篇末尾 · 只写一次** — 所有 Pn 之后另起 `# 章末回顾`，分三块（此节可用小标题）：
1. 主线回顾：三到五句串起整章从哪讲到哪、谁推出谁；
2. 重点汇总：必须记住的定义、结论、易错点，条目列出并标出对应页码；
3. 关键公式表：全章核心公式汇成一张表（公式 / 含义 / 适用条件 / 出现页），
   再补三到五个自测问题，只出题不给答案。
不要在每一页重复做整章总结。

**排版约定** — 照记号写即可，字体字号、三线表和列宽在导出 Word 时统一设置，不要手写样式：
- 正文：宋体小四（12pt）、西文 Times New Roman、首行缩进 2 字符、1.5 倍行距、两端对齐；
- 标题：黑体分级（章标题三号、页标题四号、课件小标题小四加粗）；`## Pn` 原样保留，课件小标题写成 `### …`，不要改动或新增同级页标题；
- 表格：五号宋体、学术三线表，列宽按内容自动分配；列数控制在 2~4 列，编号/页码列写短、
  公式与说明列写清楚；题注小五居中。==…== → 黄底高亮；LaTeX → Word 原生公式。
- 公式：行内 $...$、独立 $$...$$ 前后空行；多行推导分行写成多个 $$…$$，不要用 aligned
  环境的 & 对齐符（Word 会把它显示成字面量）；矩阵/行列式用 bmatrix / vmatrix，列间 & 保留；
  求和上下限写全（如 `$\sum_{\nu=1}^{3}$`），矩阵里不写中文。
整篇只用到 `## Pn`、`### 小标题`、`==…==`、`**…**`、$…$、$$…$$ 和 Markdown 表格这几种记号。

**篇幅** — 按内容密度决定，不设上限：{{MIN_CHARS}} 字只是起点；公式多、推导长、图表密的页
  写到 1500～2500 字甚至更多，每一步的依据、条件、符号含义都要讲清；
  不许为了压字数跳步、删公式或只给结论。内容少的页几百字即可，不要注水。
上面清单里与某页无关的项目直接跳过，不要每页硬凑全套。
一切以原始课件 / 截图为准，看不清就翻原件，不要猜。

**交稿前自检（写完必做，结果写进文末注释块，不要写进正文）**
1. 逐页对照原始课件 / 截图核对：所有数值、单位、尺寸、频率、材料参数、
   模式与型号编号是否真的出现在课件里；看不清或原文没有的，删掉具体数值
   改成定性描述，或明确写「由…推得」，不要伪装成课件给出的条件。
2. 检查公式：有没有抄错符号、漏条件、量纲不对、推导跳步；$…$ / $$…$$
   是否成对闭合，公式里是否混了中文、用了 aligned 的 & 对齐符、
   \begin 与 \end 是否配对。矩阵 / 行列式里用 & 分列是正常的。
3. 检查覆盖：每页都有 `## Pn` 且正文非空，没有漏页、重复页号，
   没有把下一页的内容提前写进来；全篇只在末尾写一次章末回顾。
4. 检查术语：同一概念的译名与符号前后一致；给了术语表就必须沿用。
5. 检查图表与仿真结论：讲解里写的趋势、极值、坐标范围、模式次序，
   和课件里的图 / 表是否一致；不确定就写「需对照原图确认」。
6. 检查小标题分层：课件里独立成行的小标题是否都认出来了、译成中文并用
   `### …` 单独成行；有没有把标题揉进正文、自造标题、把正文短句误当标题，
   或给本来没有小标题的页硬加。
6b. 检查编号列举：课件里 (i)(ii)(iii)、(1)(2)(3)、①②③ 这类逐条列出的
   条件 / 定义 / 事实，是不是一条占一行、逐条分段列出；有没有用分号把几条
   揉进同一段、或漏掉某条编号。正文里顺带引用某一条的不用拆。
6c. 检查跨页一致性：通读全篇，连续的推导 / 例题是否只在块的首页写了一次定位，
   块内其余页有没有又写「本页接着上一页」「承接上页」「在上一页结论基础上」
   这类复述开头；发现就删掉复述句，让续页直接从公式或论点开始。
6d. 检查符号字形：正体 Z 与花体 𝒵 若在同一份课件里同时出现，是两个不同的量
   （如网络阻抗与源 / 参考阻抗），必须逐处按课件原样区分；
   有没有误统一成一种、或写成「只是排版不同」，有就按课件改回并列入存疑。
7. 检查公式与符号的可读性：符号首次出现有没有中文名与读法；每个独立公式
   前面有没有引子、后面有没有中文解读；一段里行内公式是不是超过 3~4 个
   扎成一串。只查写法——但凡公式、字母、上下标或条件被删掉，哪怕句子变顺，
   也要作为最严重的问题列进「存疑」。
8. 检查括号与批注：有没有括号套引号、同一英文术语反复括注、把课件红笔字
   连引号抄进正文、几个相近定义挤在一段、写「P9」这类内部编号；
   发现就按页码列进存疑，建议改成直陈句和自己的话。
9. 检查去 AI 味（humanizer）：按上面的规范找「不是…而是…」对仗、段末重复
   收尾、假装深刻的格言、铺垫开场、虚构对手、硬凑三项、破折号成串、AI 高频词、
   夸大重要性、无出处权威、装饰性加粗、聊天残留。注意：只改表达，**任何公式、
   符号、条件、数值、事实都不许删改，也不许新增原文没有的细节**——一旦发现
   为顺口而删改或编造，作为最严重的问题写进「存疑」。
