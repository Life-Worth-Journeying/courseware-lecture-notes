# 手动版提示词

> 这是根号M7手动模式使用的提示词备份。Agent 使用本 Skill 时不必原样粘贴；
> 只有在把模板交给外部网页模型时，才需要复制其中一段。

> 占位符：`{{TITLE}}` 课件名；`{{TEMPLATE_PATH}}` 模板路径；`{{OUT_MD}}` 成品路径。

## 1. 详解 · 路径 + 完整提示词（发给能读本地文件的模型）

```text
请读取本地模板：
{{TEMPLATE_PATH}}

通读开头的「讲解规范」（只此一处，不要逐页重复规则），按「材料」自己读取课件与截图；逐页先认出课件里独立成行的小标题（编号行、加粗短行、中文短语），译成中文、用 `### 中文译名` 单独成行分层；每页骨架里的「本页小标题」只是线索，以截图为准补齐或纠正；课件没有小标题的页保持连续段落、绝不自己加标题。写正文时公式、字母、符号一个都不许删，但要好读：符号首次出现给中文名与读法，独立公式前有引子、后有中文解读，一段里行内公式最多 3~4 个，符号对照用表格（照样写全），绝不为了顺口删式子。英文术语只括注一次；课件上的红笔批注要改写成自己的话，不要把「红笔…」连同引号抄进正文；相近定义先讲区别再分条展开，引用别页写第N页。连续块只定位一次：先通读全部骨架，判断相邻几页是否在讲同一个推导或例题，是则只在块的首页写一句定位，块内其余页直接从续接的公式或论点开始，绝不写「本页接着上一页」「承接上页」这类复述；换主题才重新定位。正体 Z 与花体 𝒵 若同时出现在课件里，是两个不同的量，逐处按原样区分、不要统一。把每个 `【逐页讲解】` 换成整页正文，`## Pn` 原样保留；交稿时删掉开头的「材料」和「讲解规范」两段，不要把规则文字写进成品；全篇末尾按规范只写一次章末回顾。

**交稿前必须按模板末尾的「交稿前自检」逐项核对**（数值与单位有没有编造、公式有没有抄错或 LaTeX 不闭合、页码有没有漏、术语与推导是否一致、图表与仿真结论对不对、编号列举是否逐条分行、连续块是否只在首页定位），并在文件最末尾保留如实填写的
`<!-- VERIFY-REPORT … VERIFY-REPORT -->`
自检注释块：别写套话，发现问题就逐条列进「存疑」。后续检查会读它。

写完把完整 Markdown 存为：
{{OUT_MD}}

存好后运行一次程序化质检（在本 Skill 目录执行 `python scripts/qa_check.py "成品.md"`），若报硬错误就定点改掉对应页再交稿；这一步查公式闭合、页码、小标题格式、页首复述，不花模型 token。

**最后按模板里的「整篇定名」给整份稿子定中文名**：把全文当一份材料通读，不要只取第一页；把 H1 改成 `# 《新名字》`，能改文件名就把成品改名为 `新名字_讲解.md`（同目录，重名加 -2），并在 VERIFY-REPORT 之前留一行 `<!-- CN-RENAME: 新名字 -->`；改不了文件名也必须留这行，交付脚本会按它改名。

完成后回一句“已完成”。
```

## 2. 详解 · 短提示词（同一个模板，话更少）

```text
请读取本地文件 {{TEMPLATE_PATH}}，按文件开头的要求逐页补全讲解：先认出课件里独立成行的小标题、译成中文并用 `### 小标题` 单独成行分层，没有小标题的页不要自己加；再按版面顺序写正文，公式与字母一个都不删，但要给符号中文名与读法、公式前后加引子与中文解读。先通读骨架判断连续块，只在块首定位一次、块内不复述上页；正体 Z 与花体 𝒵 按课件逐处区分。并按末尾的「交稿前自检」逐项核对、保留 VERIFY-REPORT 注释块，写完先保存为同名 _讲解.md。最后按末尾的「整篇定名」通读全文，把 H1 改成 `# 《新名字》`、把文件改名为 `新名字_讲解.md`，并在 VERIFY-REPORT 之前留一行`<!-- CN-RENAME: 新名字 -->`；改不了文件名也必须留这行。保存后运行 `python scripts/qa_check.py "成品.md"` 做程序化质检，有硬错误先修再交。
```

## 3. 笔记 · 路径 + 完整提示词

```text
请读取本地笔记模板：
{{TEMPLATE_PATH}}

这是一份「可直接抄」的复习笔记模板，不是逐页详解。先通读开头的「笔记规范」（只此一处，不要逐页重复规则），按「材料」自己读取原课件和截图；把每页的 `**【本页笔记】**` 换成这一页真正要抄的内容，`## Pn` 原样保留。不要每页套「定义：/条件：/图示：/核心：」栏目，不单独设「例题」栏；公式、符号、上下标、单位和适用条件照原样；图要接本页文字或公式，不孤立描述长什么样。交稿前按模板末尾的 5 条自检逐项核对。

交稿时删掉开头的「材料」「笔记规范」和每页的「本页小标题」线索行，只留第一行标题、`## Pn` 正文；不要把规则文字写进成品。

写完把完整 Markdown 存为：
{{OUT_MD}}

存好后运行一次程序化质检（在本 Skill 目录执行 `python scripts/qa_check.py "成品.md"`），有硬错误先改对应页再交稿。

完成后回一句“已完成”。
```

## 4. 笔记 · 短提示词

```text
请读取本地笔记模板 {{TEMPLATE_PATH}}，按开头的「笔记规范」逐页把 `**【本页笔记】**` 换成可直接抄的复习笔记；`## Pn` 原样保留。不要写成逐页详解，不要每页重复「定义/条件/图示/核心」栏目，例题不单独设栏；公式与图必须接本页正文。交稿前按末尾 5 条自检核对，保存为同名 _笔记.md。
```

## 5. 详解 · 复查提示词（只挑错，不重写）

```text
请给《{{TITLE}}》的讲解稿做一次**事实复核**：只挑问题，不要改写或重写正文，也不要重新讲解。

材料：
- 讲解模板（含原始课件与截图位置、讲解规范）：
  {{TEMPLATE_PATH}}
- 已写好的讲解稿：
  {{OUT_MD}}

做法：先按模板里的「材料」读原始课件 / 截图，再逐页对照讲解稿，只找下面这几类问题：
1. 数值、单位、尺寸、频率、材料参数、模式与型号编号：讲解写了但课件里没有的，或数值对不上的；推导得出的中间量有没有写明依据。
2. 公式与推导：符号抄错、漏条件、量纲不对、跳步；LaTeX 是否闭合、公式里是否混了中文或 aligned 的 & 对齐符。
3. 顺序与覆盖：是否按版面从上到下 / 从左到右讲，有没有漏页、重复页号、把下一页内容提前写进来。
4. 术语：同一概念的译名与符号是否前后一致，是否沿用术语表。
5. 图表与仿真结论：讲解里的趋势、极值、坐标范围、模式次序，和课件图 / 表是否一致；看不清的就标「需对照原图确认」。
6. 小标题分层：课件里独立成行的小标题（编号行、加粗短行、中文短语）是否都认出来了、译成中文并用 `### 小标题` 单独成行；有没有把标题揉进正文、自造标题、把正文短句误当标题，或给本来没有小标题的页硬加。
6b. 编号列举：课件里 (i)(ii)(iii)、(1)(2)(3)、①②③ 这类逐条列出的条件 / 定义 / 事实，是不是一条占一行、逐条分段列出；有没有用分号把几条揉进同一段、或漏掉某条编号。正文里顺带引用某一条的不用拆。
7. 好读程度：符号首次出现有没有中文名与读法、独立公式前后有没有引子和中文解读、行内公式是不是扎堆成串；**只查写法，不因为不好读就删公式、字母、上下标或条件**——发现删减要作为最严重的问题列出来。
8. 括号与批注：有没有括号套引号 / 引号里再套括号、同一术语反复括注英文、把课件红笔字连引号抄进正文、把多个相近定义挤在一段、写「P9」这类内部编号；发现就按页码列出来，建议改成直陈句和自己的话。
9. 去 AI 味：按 humanizer 规范检查「不是…而是…」对仗、段末重复收尾、假装深刻的格言、铺垫开场、虚构对手、硬凑三项、破折号成串、AI 高频词、夸大重要性、无出处权威、装饰性加粗、聊天残留。**只查写法；任何公式、符号、条件、数值被删改，或新增原文没有的细节，都是最严重的问题**，即使句子因此变顺也要列出来。

输出格式（只输出问题，没问题不要凑数）：
`Pn · 类型 · 讲解里的写法 · 课件里的依据 · 建议怎么改`
最后一行写「合计：N 处存疑」。确认无误就只写「复核通过，未发现存疑项」。
不要重写讲解稿，也不要输出 VERIFY-REPORT 注释块。
```

## 6. 笔记 · 复查提示词（只挑错，不重写）

```text
请给《{{TITLE}}》的复习笔记做一次复核：只挑问题，不要重写正文。

材料：
- 笔记模板（含原课件与截图位置）：
  {{TEMPLATE_PATH}}
- 已写好的笔记稿：
  {{OUT_MD}}

先按模板读取原课件 / 截图，再逐页核对：
1. 数值、单位、频率、材料参数、型号与条件有没有课件依据；
2. 公式、符号、上下标、适用条件有没有抄错、漏项或 LaTeX 不闭合；
3. 图有没有接上本页文字/公式，是否只写了外观；
4. 有没有逐页重复「定义：/条件：/图示：/核心：」栏目，或把例题写成表演；
5. 有没有「本页/下面我们/可以看出」等空话，笔记是否真能直接抄。
按 Pn 列出问题、课件依据和建议改法；没有问题的页写「通过」，不要泛泛点评。
```
