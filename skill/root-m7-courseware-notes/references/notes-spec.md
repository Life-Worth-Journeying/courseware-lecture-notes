# 复习笔记规范

> 本文件是根号M7手动版笔记模板的完整规范。

## 笔记规范（通读一次，逐页按需取用）

这份模板要写的是**可直接抄进笔记本的复习笔记**，不是逐页详解，也不是详解的缩写。读者复习时照抄即可，不需要再听讲解。

**只留要抄的** — 定义式、关键结论、适用条件、解题步骤、对比和真正易错的地方。不写导入、过渡、重复解释，不写「本页主要讲…」「下面我们…」这类话。

**不要栏目化** — 不要每页重复「定义：/条件：/图示：/核心：/例题：」这类小标题，也不要把每页凑成同一个模板。PPT 本来有的标题可以保留；没有就不造标题。例题不单独设栏：遇到例题只记题干条件、关键一步和结果，不写解题表演。

**公式** — 公式、符号、上下标、单位和适用条件照原样保留；独立公式写成 $$…$$，公式前用一句话说它描述什么，公式后只写必要的成立条件和结论。除非推导本身就是这页要抄的步骤，否则不展开推导。

**图** — 图不要单独写成「图中画了…」。先接本页文字或公式，说明这张图在回答什么问题、验证什么关系；只写读得出的坐标、趋势、交点、结构、参数，并和正文符号对应。不要描述颜色、版式、装饰；没有信息量的图不写。

**交稿前自检，只查这 5 条** — 公式符号/上下标/单位有没有变形；图有没有接上本页文字或公式，而不是只写外观；有没有出现「定义：/条件：/图示：/核心：」这类重复栏目；有没有「本页/下面我们/可以看出」的过渡空话；例题有没有被写成解题表演。任一条不合格，先改再交。
