# 根号M7 课件讲解

把课件写成可交付的 Markdown 讲解稿或复习笔记。规范来自根号M7手动版；本 Skill 不调用软件 API，由当前 Agent 自己读取课件、逐页写作，并用脚本做确定性检查。

## 先选模式

- 用户说“逐页讲解、讲义、讲课、把课件讲透、生成讲解”→ `detail`
- 用户说“复习笔记、笔记、能直接抄、考前复习”→ `note`
- 只说“写一份/处理这份课件”且没提笔记 → 默认 `detail`
- 已有 `_讲解模板.md` 或 `_笔记模板.md` → 直接使用，不要再生成

用户可以用一句很短的话触发，例如：

```text
用根号M7规范，把这份 PDF 写成逐页讲解。
用根号M7笔记规范，把这份课件写成能直接抄的复习笔记。
```

## 工作流

1. **确认材料。** 找到原始 PDF / PPT / 逐页截图，以及可选术语表。PPT/PPTX 先导出 PDF（或导出页面图片）；不要凭文件名猜内容。
2. **没有模板就先建模板。** 在 Skill 根目录用脚本把材料位置、逐页截图、规范、`## Pn` 骨架写进模板：

```bash
python scripts/build_template.py --input 课件.pdf --out 课件_讲解模板.md
python scripts/build_template.py --input 课件.pdf --out 课件_笔记模板.md --kind note
python scripts/build_template.py --images 页面目录 --out 课件_讲解模板.md
```

   可选 `--depth brief|standard|deep|max`（默认 `deep`，每页 900 字起）、`--glossary-file 术语表.txt`。已有模板时跳过此步。
3. **只读对应规范。** `detail` 读 `references/lecture-spec.md`；`note` 读 `references/notes-spec.md`。不要同时读两份，也不要把规范原文抄进成品。
4. **逐页写作。** 把每个 `**【逐页讲解】**` / `**【本页笔记】**` 换成正文，`## Pn` 和材料中的页序原样保留。先看截图再写；每页按版面顺序推进。连续推导/例题只在块首页定位一次。
5. **程序化质检。** 写完后运行：

```bash
python scripts/qa_check.py 成品.md
# 只自动修复确定安全的两类问题（### 空行、页首复述上页）
python scripts/qa_check.py --fix 成品.md
```

   有硬错误就定点改对应页，再跑一次；不要为通过检查而删公式、符号、条件或数值。
6. **交稿收尾。** 按规范在文末保留 `<!-- VERIFY-REPORT ... -->`；按整篇内容定中文名，改 H1，能改文件名就改为 `新名字_讲解.md` / `新名字_笔记.md`，并保留 `<!-- CN-RENAME: 新名字 -->`。
7. **可选复查。** 用户要求“再挑一遍错”时，按 `references/handoff-prompts.md` 的复查提示词做第二遍：只列 Pn、问题、课件依据、建议改法，不重写正文。

## 不可协商的硬规则

- **公式、字母、上下标、矢量记号、系数、单位、适用条件、页码、`==高亮==`、`###` 小标题、编号列举的逐条分行，一个都不能少。** 只调整叙述顺序和呈现方式。
- **不编造课件里没有的数值、条件、例子、结论或出处。** 看不清就回去看原图，或写“需对照原图确认”；不要把猜测伪装成课件原文。
- 小标题只认课件版面上独立成行的编号行、加粗/大号短行、中文短语；译成中文，用 `### 中文小标题` 单独成行。没有小标题的页不要硬加。
- 公式用 LaTeX；独立公式前后要有中文引子和解读；矩阵/行列式用 `bmatrix` / `vmatrix`，矩阵内不写中文；不要用 `aligned` 的 `&`。
- 引用其它页写“第9页”，不要写“P9”；本页写“这一页”。
- 全篇只在末尾写一次 `# 章末回顾`；不要在每页重复整章总结。
- 成品只保留第一行标题、`## Pn`、课件原有的 `###` 小标题、正文、章末回顾，以及末尾两个注释块。删掉“材料”和“讲解规范”等模板说明。

## 资源

- `references/lecture-spec.md` — 逐页讲解的完整规范（含自检、篇幅、格式、去 AI 味）。
- `references/notes-spec.md` — 复习笔记的完整规范（更短，只留要抄的内容）。
- `references/handoff-prompts.md` — 手动模式的全套提示词备份；把模板交给外部网页模型时使用。Agent 自己执行本 Skill 时不需要照着念。
- `scripts/build_template.py` — 从 PDF/页面图片生成模板；需要 PyMuPDF。
- `scripts/qa_check.py` — 零 token 的程序化质检：公式闭合、环境配对、页码连续、小标题空行、编号揉段、页首复述、正/花体 Z 表述。
- `scripts/headings.py` — 从文字层识别小标题线索；只是线索，最终以截图为准。

……
